การบริหารสิทธิ์การเข้าถึง (Access Management)

ให้ผู้บริหารและ CTO เห็น User / Admin / MFA / Access Review / External Access และบัญชีที่ควรปิด

หลักการ (Control Principle): ทุกบัญชีควรระบุเจ้าของสิทธิ์ ระบบที่เข้าถึง ระดับสิทธิ์ MFA สถานะ และวันทบทวนสิทธิ์ โดยรายการที่ Data Mode = DEMO เป็นข้อมูลสมมุติเพื่อแสดงรูปแบบ Dashboard เท่านั้น
